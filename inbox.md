# Inbox

A low-friction holding area for skills and visual workflows found during the week. Duplicates are fine here; cleanup happens later.

## Quick capture template

```md
### Name
- Source: https://github.com/...
- First impression:
- Why I saved it:
- Possible category:
- Status: collected
```

## Workflow

1. Drop interesting links here first.
2. During cleanup, open the current upstream `SKILL.md` / README and verify what the project actually does.
3. Merge duplicates or closely related skills.
4. Check license / redistribution restrictions.
5. Move the useful entry into `catalog.md`; testing notes can be added later.

No requirement to fully analyze an entry when it is first collected.
